# LastGround.Gameplay

Player, Weapons, Combat, Zombies, AI, Horde, Boss, Map, Environment, Loot, Upgrades, Events.
**Mirror, UI ve Save'e referans veremez** (TDD_02 §26.1). Bağımlılık: Core, Data, Unity.Mathematics/Collections/Burst.

Tip davranışı job'da `ZombieTypeParams` tablosuyla (kütle ağırlıklı ayrılma: Tank iter, Spitter mesafe bandı + yan kayma, Exploder sprint). `IExplosionSink`/`IProjectileLauncher` host sistemlerine bağlanır |
| `Projectiles/` | `ProjectileTable` (her cihazda uçan projectile'lar; kapalı form uçuş: başlangıç → bitiş + süre, yay yüksekliği), `ProjectileSystem` (host: grenade duvara kadar, iniş + fitil → patlama; tükürük oyuncuya çarpınca hasar + yavaşlatma), `ExplosionSystem` (host: daire sorgusu, düşüş, itme, stun, zincirleme; oyuncu patlaması yalnızca atana zarar verir), `ExplosionFx` |

**Değiştirirsen etkilenenler:** `CrowdState` alanları Networking replikasyonu ve Rendering tarafından okunur. `NavGrid` formatı `Data/Map/NavGridAsset` ve Editor `NavGridBaker` ile ortaktır (harita değişince yeniden bake). `ZombieTuning` halka/saldırı mesafeleri `HordeSimulationTests`, `CombatTests` ve `ZombieTypeTests` varsayımlarını etkiler. `CrowdFlags` bitleri snapshot'ta 5 bit (`ReplicationTuning.FlagBits`); elite id'si enter mesajında tip baytının üst yarısında. Tip işleri dünya RNG'sini tüketmez (slot/nesil hash'i) — director testleri RNG akışına duyarlıdır. `HitClaim` alanları `HitClaimSync` wire formatıyla birlikte değişir (`NetProtocol.Version`).
